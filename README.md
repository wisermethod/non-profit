# Non Profit

A WISER plugin for non profit organizations: the grant writing, fundraising and operating work they run on. It ships no skills or experts yet; a Grant Expert and its related skills are the first planned.

## Install

Install Wiser first, by its [Install steps](https://github.com/wisermethod/wiser#install): this plugin loads beside it. Then add this plugin in the same app:

- **Claude Cowork.** Open Customize, then Plugins, then Add marketplace. Give it `https://github.com/wisermethod/non-profit`, and install `non-profit`. Then turn on Sync automatically for this marketplace, as Wiser's steps do for theirs.
- **Claude Code.** Run `claude plugin marketplace add wisermethod/non-profit`, then `claude plugin install non-profit@wiser-method-non-profit`, and start Claude Code in your working folder.
- **Codex.** Add `wisermethod/non-profit` as a marketplace and install `non-profit`.
- **ChatGPT for desktop.** Add `wisermethod/non-profit` as a marketplace and install `non-profit`.
- **Grok.** Run `grok plugin marketplace add wisermethod/non-profit`, then `grok plugin install non-profit --trust`.
- **Cursor.** Add your clone of this repository as a workspace root beside your clone of Wiser and your working folder.

Work lands in the working folder you attach, never in this repository.
