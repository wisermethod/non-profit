# Non Profit

A WISER plugin for not-for-profits, schools, and other public entities.

Not yet built. This repository reserves the name and holds the place; there is nothing to install.

## Status

Empty and unscoped as of 2026-09-03. The plugin has no skills, experts, tools, or connectors yet, and no build has been planned.

## What it will be

A harness-agnostic capability plugin in the same shape as the other WISER plugins: an authoring tree of skills, experts, tools, and connectors, projected into an installable bundle, governed by a runtime charter. It will run wherever a plugin of that shape can be loaded.

It loads alongside the Wiser plugin and assumes Wiser is installed. Wiser stays the writing, playbook, and connecting layer; this plugin is the grant writing, fundraising, and public-entity bench on top of it.
